# Third-party sources and licenses

## M-Abozaid/esp32-c3-adblock — primary architectural reference

Public repository: <https://github.com/M-Abozaid/esp32-c3-adblock>

The repository page was inspected on 2026-10-31. It describes an MIT-licensed
ESP32 DNS sinkhole which stores sorted 40-bit FNV-1a domain hashes in flash and
binary-searches them. This project independently implements that documented
design for an ESP32-S3; no source files, binaries, blocklists, credentials, or
web dashboard code were copied. The upstream source checkout was not permitted
in this workspace, so this is not a line-by-line source or license-file audit.
